隐私说明

账号和密码只保存在本机 %APPDATA%\guatnet\config.json，不会上传到任何服务器，程序也没有统计、埋点或远程上报。
运行时的网络请求只有两类：向你在「通用设置」里填写的校内认证网关（通常是 10.x 内网地址）提交登录参数；以及启动约 30 秒后或手动点击「检查更新」时，读取 GitHub 公开 Release 的版本信息；确认更新时从 GitHub 下载安装包。不上传账号、密码或使用数据。
日志文件同样只存在本机，且其中密码一律显示为 ***。

实现原理

按经典 Dr.COM 认证接口实现：向门户的 /drcom/login 提交账号、密码和运营商编号，再解析返回的 result 字段判断成败。
程序在此协议之上补了断线检测、返回结果校验和日志脱敏，具体实现见项目源码。
